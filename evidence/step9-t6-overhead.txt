AN ERROR IN THE FIRST CAPTURE ATTEMPT, RECORDED
================================================================================

The first version of this capture ended with a hardcoded line reading "The
end-to-end delta is SMALLER than the noise floor." That was true of an earlier
session. In this capture the end-to-end delta was larger, not smaller — the
conclusion had been written from the previous run's numbers and printed
regardless of what was measured.

It would have appeared in this file as a statement contradicted by the table
directly above it.

The capture was regenerated with its findings computed from the runs rather than
asserted, including the branch for whether the delta range spans zero. If a
future run produces a different shape, the text changes with it.

This is the same failure as recording "no alert of any kind" from a run whose
threshold was set above the condition being tested: a conclusion carried forward
past the data that supported it.
