addresses belong to one machine. Neighbour entries are perishable and were

6. PSEUDONYM MAPPING
================================================================================

Shared with the other files in evidence/ — the same token denotes the same device
everywhere it appears.

    <tg-nic>            primary host wifi NIC
    <daddy-nic>         ledger host wifi NIC
    <router>            home router
    <tg-v6>             primary's stable global IPv6 /128
    <daddy-v6>          ledger's global IPv6 address
    <daddy-linklocal>   ledger's fe80:: address

In a ufw log line the MAC field is destination:source:ethertype. The ethertype is
kept verbatim because it is evidentiary — 08:00 is IPv4, 86:dd is IPv6 — and it
is not identifying. Keeping the two NIC halves distinct is what separates
router-relayed traffic from traffic sent directly on the LAN, which is how group
1 is told apart from groups 2 and 3.

Real values are withheld because a link-layer address is a permanent, globally
unique device identifier and a routable IPv6 address carries the home network's
ISP-delegated prefix. Neither is evidentiary. Everything that is has been kept.
